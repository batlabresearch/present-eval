구글 시트 하나로 발표 심사 준비하기

시트에 행사명, 평가항목, 발표자 명단을 적으면 심사위원은 휴대폰으로 링크를 열어 평가하고, 주최 측은 관리자 화면에서 부문별 순위를 바로 봅니다. 결과는 주최 측 구글 계정의 시트에만 저장됩니다.

01시트 준비처음 5분

방법 1. 템플릿 시트 복사

아래 버튼을 누르면 내 구글 드라이브에 샘플이 든 시트가 복사됩니다. 코드도 함께 복사되니 02로 넘어가세요.

템플릿 시트 사본 만들기 ↗

새 시트에 코드 붙여 넣기

  1. sheets.new에서 빈 구글 시트를 만들고 이름을 정합니다. (예: 2026 춘계 학술대회 심사)
  2. 그 시트의 메뉴 [확장 프로그램 → Apps Script]를 엽니다. script.google.com에서 따로 만든 프로젝트는 시트에 붙지 않아서 쓸 수 없습니다.
  3. 편집기에 있는 내용을 모두 지우고, 아래 버튼으로 복사한 코드를 붙여 넣은 뒤 저장(Ctrl+S)합니다.
    코드 파일 열기
  4. 시트 탭으로 돌아와 새로고침하면 메뉴에 [발표 심사]가 생깁니다. [발표 심사 → 처음 설정]을 누릅니다.
  5. 처음 한 번 권한 승인 창이 뜹니다. 본인 계정을 고르고 허용합니다. "Google에서 확인하지 않은 앱"이 나오면 [고급 → (프로젝트 이름)(으)로 이동]을 누릅니다. 내가 만든 코드라서 나오는 경고입니다.

샘플 내용이 든 [설정]·[평가항목]·[발표자] 탭이 생깁니다.

02시트 채우기탭 3개

탭적는 것
설정 행사명, 관리자 비밀번호(꼭 적어야 결과를 볼 수 있음), 첫 화면 문구(큰 제목, 슬로건, 기관명), 의견 칸 이름. 왼쪽 칸의 이름은 바꾸지 마세요.
평가항목 한 줄에 항목 하나: 발표유형 · 평가항목 · 배점 · A~E 점수. 화면에 위에서부터 이 순서로 나옵니다. A~E 칸을 비워 두면 배점의 100·90·80·70·60%로 계산합니다. 배점 합이 꼭 100일 필요는 없습니다.
발표자 한 줄에 발표자 한 명: 발표유형 · 부문 · 이름 · 발표주제 · 지도교수 · 발표시간. 적은 순서대로 화면에 나옵니다. 지도교수 칸의 머리글은 '소속'처럼 바꿔도 되고, 바꾼 이름이 화면에 나옵니다.
  • 발표유형 이름(예: 구두발표, 포스터발표)은 [평가항목]과 [발표자] 탭에서 글자까지 같아야 합니다. 발표유형이 하나뿐이어도 됩니다.
  • 순위는 부문마다 따로 매깁니다. 부문을 비워 두면 발표유형 이름을 부문으로 씁니다.
  • 발표시간은 13:00 - 13:20처럼 적습니다. 한 부문의 발표자가 모두 같은 시간이면(포스터 세션처럼) 부문 시간으로 보여 줍니다.
  • 다 적은 뒤 [발표 심사 → 설정 점검]을 누르면 빠뜨린 것이나 잘못 적은 줄을 알려 줍니다.

03웹 앱으로 배포처음 한 번

  1. [확장 프로그램 → Apps Script]에서 오른쪽 위 [배포 → 새 배포]를 누릅니다.
  2. 유형 선택(톱니바퀴)에서 웹 앱을 고릅니다.
  3. 다음 사용자 인증 정보로 실행: 나, 액세스 권한이 있는 사용자: 모든 사용자로 두고 [배포]를 누릅니다.
  4. [액세스 승인] 버튼이 나오면 누르고, 권한 승인 창에서 본인 계정 → (경고가 나오면 [고급 → 이동]) → [허용]을 누릅니다.
  5. 배포가 끝나면 나오는 웹 앱 URL을 엽니다. 심사위원 링크와 관리자 링크가 나옵니다.

링크는 나중에 시트 메뉴 [발표 심사 → 심사 링크 보기]에서 다시 볼 수 있습니다. 시트 내용(명단, 점수표, 문구)을 고칠 때는 다시 배포하지 않아도 바로 반영됩니다.

학교·기관(Google Workspace) 계정에는 '모든 사용자'가 없을 수 있습니다. 그럴 때는 개인 Gmail 계정으로 시트를 만드세요.

04행사 당일

심사위원 심사위원 링크를 열고 이름을 적은 뒤 발표유형을 고릅니다. 발표자마다 항목별로 등급을 고르고 제출합니다. 입력 내용은 그 기기에 자동 저장되고, 같은 이름으로 다시 제출하면 이전 제출을 덮어씁니다. 이름은 매번 똑같이 적어야 합니다(이교수와 이 교수는 다른 사람으로 셉니다).
주최 측 관리자 링크를 열고 [설정] 탭의 비밀번호를 넣습니다. 부문별 순위, 심사위원별 점수와 등급, 의견, 제출 현황을 보고, 엑셀(CSV)로 내려받거나 인쇄할 수 있습니다. [새로고침]을 누르면 최신 제출이 반영됩니다.

심사위원 링크는 QR 코드로 만들어 행사장에 붙여 두면 편합니다. 관리자 링크는 비밀번호가 있어야 열리지만 공유하지 않는 것이 좋습니다.

06다음 행사

  • 새 시트로 하기: 지난 시트에서 [파일 → 사본 만들기]를 하고, 사본에서 03(배포)을 다시 합니다. 링크가 새로 생기고, 지난 결과와 완전히 나뉩니다.
  • 같은 시트로 하기: [발표 심사 → 결과 보관하고 새 행사 시작]을 누릅니다. 응답 탭이 '보관…' 이름으로 남고, 링크는 그대로 씁니다. 그다음 탭 3개를 새 행사에 맞게 고칩니다.

07점수 계산 방식

  1. 항목마다 고른 등급을 [평가항목] 탭의 점수로 바꿉니다. (예: 배점 45점 항목의 B = 40.5점)
  2. 심사위원마다 항목 점수를 더해 총점을 냅니다.
  3. 발표자마다 평가한 심사위원들의 총점 평균을 냅니다. "평가 안 함"은 평균에서 빠집니다.
  4. 부문 안에서 평균이 높은 순서로 순위를 매깁니다. 평균이 같으면 같은 순위입니다(1, 2, 2, 4).

관리자 화면의 "합계"는 참고용입니다. 평가한 심사위원 수가 발표자마다 다르면 합계로는 비교할 수 없습니다.

08문제 해결

화면에 나온 말확인할 것
서버에 연결하지 못했습니다웹 앱 배포의 액세스가 모든 사용자인지, 링크의 ?s= 뒤가 잘리지 않았는지 확인합니다.
연결된 시트를 찾지 못했습니다배포를 지웠거나 링크가 틀린 경우입니다. 시트 메뉴 [발표 심사 → 심사 링크 보기]의 링크를 다시 보내세요.
시트의 행사 설정에 문제가 있어서 열 수 없습니다[발표 심사 → 설정 점검]을 눌러 오류를 고칩니다. 보통 [평가항목]과 [발표자] 탭의 발표유형 이름이 다른 경우입니다.
관리자 비밀번호를 먼저 적어 주세요[설정] 탭의 관리자 비밀번호 칸을 채웁니다.
심사위원 이름 오타로 두 명처럼 집계됨시트의 응답 탭(응답_발표유형)에서 심사위원 칸을 직접 고칩니다.
코드를 고쳤는데 그대로임코드를 고쳤을 때만 [배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포]를 합니다. 링크는 그대로입니다.
