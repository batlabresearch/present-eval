# 발표 심사 평가 (공용)

학술대회·경진대회처럼 여러 심사위원이 발표자를 A~E 등급으로 채점하는 행사를 위한 웹앱입니다.
행사 내용(행사명, 평가항목과 점수표, 발표자 명단)은 **각 행사의 구글 시트**에서 고치고, 화면은 이 사이트 하나를 모든 행사가 함께 씁니다.

- **주최자 안내:** [`guide.html`](guide.html). 시트 준비부터 배포, 링크 공유, 다음 행사까지 다룹니다.
- **심사위원 화면:** `index.html?s=<배포 ID>`
- **관리자 화면:** `admin.html?s=<배포 ID>`
- `?s=` 없이 열면 샘플 행사로 동작하는 테스트 모드입니다. 제출 내용은 그 브라우저에만 저장됩니다.

## 구조

```
[심사위원 휴대폰]  index.html?s=ID ─ 설정 요청·제출 ─▶ [그 행사의 Apps Script 웹 앱] ─▶ [그 행사의 구글 시트]
[관리자 PC]       admin.html?s=ID ─ 결과 요청(비밀번호) ─▶        (Code.gs)              설정 · 평가항목 · 발표자
                                                                                       응답_발표유형 · 제출기록
```

- 이 사이트(GitHub Pages)는 화면만 제공하고, 데이터는 저장하지 않습니다. 결과는 주최 측 시트에만 저장됩니다.
- `?s=`에는 Apps Script 배포 ID만 받습니다. 서버 주소는 항상 `https://script.google.com/macros/s/<ID>/exec`로 만듭니다.
- 브라우저 저장소 이름에 배포 ID와 행사 번호를 넣어서, 한 기기로 여러 행사를 심사해도 섞이지 않습니다.
- 시트에는 등급(A~E)만 저장하고, 점수는 관리자 화면이 시트의 점수표로 그때그때 계산합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `assets/app.js` | 심사위원 화면 |
| `admin.html`, `assets/admin.js` | 관리자 화면: 부문별 순위, 심사위원별 점수, 의견, 제출 현황, CSV, 인쇄 |
| `guide.html` | 주최자 안내 |
| `assets/common.js` | 공통 기능: 시트 연결(`?s=`), 행사 설정 불러오기, 저장소, 서버 통신, 테스트 모드 |
| `assets/style.css`, `assets/hero-art.js` | 디자인과 첫 화면 배경 그래픽 |
| `assets/sample-config.js` | 테스트 모드의 샘플 행사. `tools/build-sample.js`로 만듭니다 |
| `config.js` | 사이트 설정: 템플릿 시트 주소(`templateUrl`), 기본 배포 ID |
| `apps-script/Code.gs` | 각 행사 시트에 붙여 넣는 서버 코드. 시트 탭 읽기, 제출 저장, 결과 조회, 시트 메뉴 |

## 고칠 때

- **샘플 행사를 바꿀 때:** `Code.gs`의 `sampleTabs_()`를 고친 뒤 `node tools/build-sample.js`를 실행합니다. 처음 설정으로 만들어지는 시트 탭과 테스트 모드 화면이 같은 내용이 됩니다.
- **사이트 주소가 바뀔 때:** `Code.gs` 맨 위의 `APP_URL`을 고칩니다. 링크 안내 화면이 이 주소로 링크를 만듭니다.
- **템플릿 시트를 만들었을 때:** 시트 주소 끝의 `/edit…`를 `/copy`로 바꿔 `config.js`의 `templateUrl`에 넣습니다. 주최자 안내에 [템플릿 시트 사본 만들기] 버튼이 생깁니다.
- `Code.gs`를 고치면 이미 배포된 행사 시트에는 반영되지 않습니다. 각 시트의 Apps Script에 새 코드를 붙여 넣고 [배포 관리 → 새 버전]으로 다시 배포해야 합니다.

## 내 컴퓨터에서 미리 보기

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `?s=` 없이 열면 샘플 행사(테스트 모드)입니다.
